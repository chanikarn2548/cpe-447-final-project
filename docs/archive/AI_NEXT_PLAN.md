## ทำงานกับข้อมูลจริง

หน้าเว็บ: เปิดเคส → เพิ่ม/เก็บเบาะแส → ตรวจตัวตนจากหลักฐานจริง → เลือก “ตรง / ไม่ตรง” → ส่งออกคู่ภาพ ไม่ใช้คำทำนาย AI เป็น label ยืนยัน และไม่ใช้เคสเดโมเป็นหลักฐานประเมิน

```
node training/prepare_field_pairs.mjs <ไฟล์คู่ภาพที่ส่งออก.json>
node training/check_field_readiness.mjs
node training/evaluate_field_pairs.mjs <โฟลเดอร์ที่เตรียมสำเร็จ>
```

ตัวตรวจใหม่เชื่อมเข้า evaluator แล้ว จะเขียน readiness.json ก่อนประเมิน รายงานรวมอยู่ training-data/field-pairs/readiness-summary.json นอก web root หากข้อมูลขัดแย้งต้องแก้จากหลักฐานต้นทาง ไม่เดาว่าคู่ไหนถูกเพื่อให้ตัวเลขผ่าน

## ผลรอบนี้

- เพิ่ม field-readiness.mjs และ CLI ตรวจข้อมูลรายชนิด
- แก้ splitPairs ให้ปฏิเสธภาพเดียวที่ติด label คนละชนิด แม้คนละคู่ภาพ
- เพิ่มการทดสอบข้อมูลว่าง, label ไม่ครบ, ภาพ/เคส/กลุ่มข้าม split และชนิดขัดแย้ง
- ทดสอบรวมผ่าน 46 ข้อ
- ไม่ได้ฝึกเพิ่มหรือเปลี่ยนโมเดลเว็บรอบนี้ ความแม่นยำเว็บยังไม่เปลี่ยน

โมเดลเว็บ HSC Top5 61/128 (47.66%) เป็น regression benchmark ที่เคยดูแล้ว ไม่ใช่ field accuracy การทดลองรุ่นใหญ่และ mirror ไม่ผ่าน validation; รายละเอียดอยู่ training/FROZEN_ALTERNATIVES_RESULTS.md
