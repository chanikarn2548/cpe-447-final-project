# สรุปบรีฟโครงงาน “ตามน้อง”

เอกสารนี้รวบรวมแนวคิดและความต้องการที่คุยกันไว้ เพื่อใช้เป็นแนวทางพัฒนาต่อและอธิบายโครงงาน

## 1. แนวคิดโครงงาน

“ตามน้อง” เป็นระบบช่วยประกาศและตามหาสัตว์เลี้ยงหาย โดยใช้รูปภาพเป็นจุดเริ่มต้น ให้เจ้าของหรือผู้พบสัตว์ลงข้อมูลได้ง่าย และช่วยรวบรวมเคส/เบาะแสที่อาจเกี่ยวข้องไว้ในที่เดียว

## 2. ปัญหาและเหตุผล

เมื่อสัตว์เลี้ยงหาย เจ้าของมักต้องโพสต์ตามกลุ่ม Facebook หลายกลุ่มและคอยตรวจดูโพสต์สัตว์ที่มีคนพบ การค้นหาและเปรียบเทียบภาพด้วยตัวเองใช้เวลา เบาะแสอาจกระจัดกระจาย และผู้แจ้งพบไม่จำเป็นต้องรู้รายละเอียดของสัตว์มาก่อน

ระบบจึงตั้งใจลดขั้นตอนเริ่มต้น: ให้ลงรูปก่อน แล้วค่อยเติมรายละเอียดเมื่อพร้อม พร้อมช่วยจัดลำดับภาพ/เคสที่ดูคล้ายเพื่อให้ตรวจสอบต่อได้เร็วขึ้น

## 3. ผู้ใช้หลัก

- เจ้าของสัตว์ที่ต้องการประกาศตามหาสัตว์หาย
- คนที่พบสัตว์หรือเห็นเบาะแส และต้องการแจ้งข้อมูลให้เจ้าของ
- คนในชุมชนที่ช่วยดู แชร์ หรือส่งต่อประกาศ

## 4. เป้าหมายด้านการใช้งาน

- เข้าถึงง่าย ใช้จากมือถือได้ และไม่บังคับสมัครสมาชิกก่อนแจ้งพบสัตว์
- เริ่มต้นด้วยการอัปโหลดรูปได้ ไม่ต้องกรอกแบบฟอร์มยาว
- รายละเอียด เช่น ชื่อ สายพันธุ์ สี บริเวณ เวลา และช่องทางติดต่อ เป็นข้อมูลที่ค่อยเพิ่มหรือแก้ภายหลังได้
- มีทะเบียนโปรไฟล์สัตว์เลี้ยงให้เจ้าของเตรียมรูปและจุดสังเกตไว้ล่วงหน้า แต่ไม่ควรเป็นขั้นตอนบังคับ
- แสดงสถานะและข้อมูลตัวอย่างให้ผู้ใช้เข้าใจว่าอะไรเป็นข้อมูลเดโม

## 5. ขอบเขตฟีเจอร์ที่ต้องการ

### ลงประกาศและแจ้งพบ

- ลงรูปสัตว์หายเพื่อเริ่มค้นหาได้
- แจ้งพบสัตว์ด้วยรูปเป็นขั้นตอนแรก ส่วนชนิดสัตว์ ลักษณะเด่น บริเวณ และเวลาที่พบสามารถเพิ่มภายหลัง
- เพิ่มหรือแก้รายละเอียดประกาศเดิมได้
- มีข้อมูลเคสและเบาะแสที่บันทึกไว้ให้กลับมาตรวจสอบ

### เปรียบเทียบภาพด้วย AI

- นำภาพที่อัปโหลดไปเทียบกับภาพเคส/เบาะแสที่มีในระบบ
- เรียงผลที่ภาพดูคล้ายขึ้นก่อน และแสดงแหล่งที่มาหรือลิงก์ของเบาะแส
- รองรับสัตว์หลายประเภท โดยกลุ่มหลักคือสุนัขและแมว และต้องการรองรับนก/สัตว์อื่นด้วย
- คะแนนเป็นเพียงความคล้ายของภาพ ไม่ใช่การยืนยันว่าเป็นสัตว์ตัวเดียวกัน ผู้ใช้ต้องตรวจสอบข้อมูลอื่นประกอบ

### Facebook และแหล่งข้อมูลภายนอก

- ต้องการให้ผู้ใช้เห็นโพสต์หรือเบาะแสที่อาจคล้ายจาก Facebook/แหล่งอื่นหลังส่งรูป
- แนวทางเดโมที่ทำได้: ผู้ใช้ใส่ลิงก์โพสต์และรูป/ภาพหน้าจอเอง หรือเชื่อม Meta API กับเพจสาธารณะที่มีสิทธิ์อ่าน แล้วให้ระบบนำภาพมาเทียบกับเคสในระบบ
- การแชร์ประกาศไป Facebook ให้เจ้าของตรวจข้อความ เลือกกลุ่ม และโพสต์เองได้
- ระบบเดโมค้นได้เฉพาะโพสต์รูปจากเพจสาธารณะที่กำหนดไว้และ Meta API อนุญาต ไม่ได้อ่านโพสต์ในกลุ่มปิดหรือค้นโพสต์ Facebook ทั้งหมดโดยอัตโนมัติ
- การจับคู่ใช้ภาพจากโพสต์ที่อ่านได้มาเปรียบเทียบ ไม่ใช่การค้นย้อนภาพทั่ว Facebook หรือทุกแอปแบบครอบคลุม

## 6. แนวทางหน้าตา UI

- โทนสีส้ม/เหลืองสดใส ตัดกับพื้นหลังสีอ่อน ให้ความรู้สึกเป็นมิตร
- ใช้ภาพหรือไอคอนสัตว์ เช่น สุนัข แมว นก และสัตว์อื่น
- มีการ์ดเลือกชนิดสัตว์ การ์ดเคส สถานะ/ตัวกรอง ส่วนค้นหา และแถบนำทางที่เหมาะกับมือถือ
- ต้องการ UI ที่ดูมีองค์ประกอบและรายละเอียดมากขึ้น แต่ยังสแกนสายตาง่ายและไม่ทำให้การแจ้งสัตว์กลายเป็นแบบฟอร์มยาว
- ปุ่มหลักควรชัด เช่น “ลงรูปเพื่อตามหา” และ “แจ้งพบสัตว์”

## 7. ประโยชน์ที่คาดหวัง

- ลดเวลาเริ่มประกาศตามหาและส่งเบาะแส
- ช่วยรวบรวมประกาศ/เบาะแสให้อยู่เป็นระเบียบและค้นกลับได้
- ช่วยคัดภาพที่น่าจะเกี่ยวข้องให้ตรวจสอบก่อน ลดภาระการไล่ดูทีละโพสต์
- เปิดโอกาสให้คนในพื้นที่ช่วยกันส่งข้อมูลและแชร์ต่อ

## 8. ข้อจำกัดและขอบเขตเดโมปัจจุบัน

- ข้อมูลที่ผู้ใช้เพิ่มในเดโมเก็บในเบราว์เซอร์ของเครื่องนั้น ไม่ได้ซิงก์ข้ามเครื่องโดยอัตโนมัติ
- เคสตัวอย่างในระบบเป็นข้อมูลสมมติสำหรับทดลอง
- การเทียบภาพเป็นการจัดอันดับความคล้าย มีโอกาสคลาดเคลื่อน โดยเฉพาะสัตว์ต่างชนิดหรือภาพที่มุม/แสงต่างกัน
- การเชื่อมต่อ Facebook แบบค้นทุกโพสต์หรืออ่านกลุ่มปิดไม่ได้รวมอยู่ในเดโม
- หากจะใช้งานร่วมกันหลายคน ต้องเพิ่มฐานข้อมูลและโฮสต์ระบบ รวมทั้งจัดการความเป็นส่วนตัวและการติดต่อเจ้าของ

## 9. วิธีทดลองเดโม

จากโฟลเดอร์นี้ เปิด PowerShell แล้วรัน:

```powershell
npm install
npm start
```

จากนั้นเปิด `http://127.0.0.1:4173/` ในเบราว์เซอร์

ดูคำแนะนำทางเทคนิคและขั้นตอนทดลองเพิ่มเติมใน `README.md`
